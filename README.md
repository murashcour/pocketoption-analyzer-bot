# PocketOption Analyzer Bot

[Русский](README.md) | [English](README.en.md)

Автоматический торговый бот для PocketOption (демо/реальный счёт).
Анализирует OTC и Real-валютные пары, выдаёт сигналы и торгует
по стратегии с мартингейлом внутри серии.

## Важно

**Проект создан при поддержке DeepSeek AI** (deepseek.com).

Архитектура, логика стратегии и код разработаны в диалоге с AI-ассистентом.
Все решения по стратегии приняты владельцем проекта, AI помог с реализацией,
отладкой и документацией.

**Бот предназначен для демо-счёта.** Использование на реальном счёте —
на ваш риск. Автор не несёт ответственности за финансовые потери.

## Возможности

- 📊 Мульти-таймфрейм анализ: 1м + 5м + 15м
- 🎯 Индикаторы: SMA14, EMA20, EMA50, RSI14
- 📈 Фильтры: уровни S/R, ATR (волатильность), свечные паттерны
- 🌍 Real-пары (Currency / Forex): OTC + реальные валютные пары
- 💰 Мартингейл: до 4 ступеней (1% → 2% → 4% → 8%)
- 🔄 Ротация пар: смена при пропусках или минусовой серии
- 💹 Payout-фильтр: OTC [90, 95]%, Real [85, 92]%
- 🔍 Payout-проверка перед 2/3/4 ступенью: при падении payout — смена пары
- ⚡ Догон 2-й ступени (`pure_martingale`): по исходному сигналу, 0 сек
- 🛡 Защита от просадки: СТОП при -30% (1 просадка, без паузы)
- 🛑 Пауза после 4 минусов подряд: 30 минут
- 📰 Пауза при важных новостях (TradingView Calendar)
- ⏱ Автостоп через 24 часа работы
- ⚙️ Интерактивное меню: 30+ параметров настройки
- 🖥️ Работа через screen: не теряется при обрыве SSH
- 🎮 Ручной режим анализатора (`--show-only` / `--confirm`)

## Требования

- **Debian-based сервер:**
  - Ubuntu 24.04.5 LTS (рекомендуется, проверено)
  - Debian 12+ (совместимо)
- Python 3.10+
- Аккаунт PocketOption (демо или реальный)
- SSID токен (получается через браузер, живёт 6–12 часов)
- **VDS в рекомендованной стране** (см. [docs/SETUP.md](docs/SETUP.md)).
  **Не Россия:** PocketOption блокирует IP из РФ (санкции).
  Нужен Гонконг, Турция, Казахстан, Таиланд, Сербия.

## Установка

Склонировать репозиторий:

    git clone https://github.com/murashcour/pocketoption-analyzer-bot.git
    cd pocketoption-analyzer-bot

Создать виртуальное окружение:

    python3 -m venv venv
    source venv/bin/activate

Установить зависимости:

    pip install -r requirements.txt

Получить SSID (см. docs/SSID.md) и сохранить:

    echo '42["auth",{...}]' > ~/.po_ssid
    chmod 600 ~/.po_ssid

## Запуск

Запуск в screen (не теряется при обрыве SSH):

    ./run.sh

Или вручную:

    screen -S bot
    source venv/bin/activate
    export PO_SSID="$(cat ~/.po_ssid)"
    python analyzer_bot.py

При запуске бот показывает интерактивное меню:

    ТЕКУЩИЕ НАСТРОЙКИ
    [1]  expiration = 60
    ...
    Номер — изменить
    Enter — торговать
    r — сброс на дефолты
    q — выход

**Важно:** после `./run.sh` зайди в screen (`screen -d -r bot`) и нажми **Enter**.
Иначе бот будет ждать ввода в меню.

Выйти из screen без остановки бота: **Ctrl+A**, затем **D**.
**Не нажимай Ctrl+C** — это остановит бота.

## Остановка

Мягко (дождаться конца текущей серии, до 3–5 минут):

    ./stop.sh

Жёстко (сразу):

    pkill -9 -f "python analyzer_bot.py"
    screen -wipe
    rm -f stop.flag

## Стратегия

1. **Анализ 1м** — RSI + 3 MA + свечной паттерн
2. **Проверка 5м** — RSI должен совпадать с 1м
3. **Проверка 15м** — RSI не в крайних зонах + конфликт направления
4. **Уровни S/R** — не входим близко к уровням
5. **Волатильность** — ATR14 ≥ 0.008%
6. **Payout пары** — OTC [90, 95]%, Real [85, 92]%
7. **Серия** — до 4 ступеней с удвоением (1% → 2% → 4% → 8%)
8. **После плюса** — остаёмся, лимит 3 пропуска
9. **После минуса** — смена пары, лимит 2 пропуска

### Мартингейл (4 ступени)

- **1-я** — полный анализ, вход в начале 1м свечи
- **2-я** — догон по исходному сигналу (`pure_martingale: true`, 0 сек).
  Если payout исходной пары упал — смена пары + анализ под новую.
- **3-я** — с анализом (проверка, может сменить направление/пару)
- **4-я** — с анализом (проверка)

**Payout-проверка** перед 2/3/4: если payout вне диапазона — смена пары,
пока не найдётся с хорошим payout. Серия не закрывается, а продолжается
на новой паре.

### Защита

- **Просадка 30%** — при падении баланса на 30% от reference → **СТОП**
  (1 просадка, без паузы)
- **4 минуса подряд** — пауза 30 минут
- **Новости** — пауза за 10 мин до и 20 мин после (High + Medium, USD/EUR/GBP/JPY)
- **Автостоп** — через 24 часа работы

## Ручной режим (анализатор)

Бот поддерживает ручной режим для тестирования стратегий:

    # Только показывает сигналы, ничего не открывает
    python analyzer_bot.py --show-only

    # Показывает, спрашивает, открывает по y
    python analyzer_bot.py --confirm

**Что делает:**
- Проверяет payout пары
- Запускает `full_analysis` (1м + 5м + 15м + S/R + ATR)
- Показывает сигнал (CALL/PUT), пару, цену
- В `--confirm` — спрашивает ставку и подтверждение

**Команды в процессе:**
- `Enter` — продолжить (та же пара)
- `s` — сменить пару
- `q` — выход

**Зачем:** проверить, как стратегия отрабатывает на разных парах,
без риска автоматических серий. Полезно для отладки порогов RSI,
S/R, ATR перед запуском в автомате.

## Конфигурация

Все настройки — в `config.json` (создаётся при первом запуске).
Ключевые параметры:

| Параметр | Значение | Описание |
|---|---|---|
| `martingale_steps_count` | 4 | Ступеней в серии |
| `pure_martingale` | true | Догон 2-й по исходному сигналу |
| `payout_min_otc` / `max` | 90 / 95 | Payout OTC (%) |
| `payout_min_real` / `max` | 85 / 92 | Payout Real (%) |
| `max_drawdown_percent` | 30 | Просадка для СТОП (%) |
| `drawdown_max_count` | 1 | Просадок до СТОП |
| `pause_after_losses` | 4 | Минусов подряд до паузы |
| `pause_after_losses_sec` | 1800 | Пауза (сек) |
| `max_runtime_hours` | 24 | Автостоп (часы) |
| `base_percent` | 1.0 | % от баланса (при ≥ $100) |
| `fixed_steps` | [1,2,4,8] | Фикс ставки (при < $100) |

Полный список — в docs/CONFIG.md.
