# PocketOption Analyzer Bot

[Русский](README.md) | [English](README.en.md)

Автоматический торговый бот для PocketOption (демо/реальный счёт).
Анализирует OTC-валютные пары, выдаёт сигналы и торгует по стратегии
с мартингейлом внутри серии.

## Важно

**Проект создан при поддержке DeepSeek AI** (deepseek.com).

Архитектура, логика стратегии и код разработаны в диалоге с AI-ассистентом.
Все решения по стратегии приняты владельцем проекта, AI помог с реализацией,
отладкой и документацией.

**Бот предназначен для демо-счёта.** Использование на реальном счёте —
на ваш риск. Автор не несёт ответственности за финансовые потери.

## Возможности

- Мульти-таймфрейм анализ: 1м + 3м + 10м
- Индикаторы: SMA14, EMA20, EMA50, RSI14
- Фильтры: уровни S/R, ATR (волатильность), свечные паттерны
- Мартингейл: 1% → 2% → 4% → 8% от баланса
- Ротация пар: смена при пропусках или минусовой серии
- Payout-фильтр: [85, 92]% с перепроверкой каждые 30 минут
- Интерактивное меню: настройка параметров при запуске
- Работа через screen: не теряется при обрыве SSH

## Требования

- Python 3.10+
- Ubuntu 20.04+ / Debian 11+ / другой Linux
- Аккаунт PocketOption (демо или реальный)
- SSID токен (получается через браузер)

## Установка

Склонировать репозиторий:

    git clone https://github.com/murachour/pocketoption-analyzer-bot.git
    cd pocketoption-analyzer-bot

Создать виртуальное окружение:

    python3 -m venv venv
    source venv/bin/activate

Установить зависимости:

    pip install -r requirements.txt

Задать SSID (получить через браузер, см. docs/SSID.md):

    export PO_SSID='42["auth",{...}]'

Запустить:

    python analyzer_bot.py

## Стратегия

1. Анализ 1м — RSI + 3 MA + свечной паттерн
2. Проверка 3м — RSI должен совпадать с 1м
3. Проверка 10м — RSI не в крайних зонах
4. Уровни S/R — не входим близко к уровням
5. Волатильность — ATR14 >= 0.1%
6. Payout пары — [85, 92]%
7. Серия — до 4 ступеней с удвоением
8. После плюса — остаёмся, лимит 5 пропусков
9. После минуса — смена пары, лимит 1 пропуск
